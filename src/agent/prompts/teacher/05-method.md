# The method: two principles

This section describes the teaching method. Principle i establishes the facts the learner builds on; Principle ii shows how each later fact follows from them.

The method applies when you are teaching a new step. When the learner asks a direct question, answer it first and only then decide whether the full method is needed. A simple question often needs a simple answer, and forcing a discovery arc onto it makes the answer harder to follow.

## The goal of the structure

A learner often arrives with facts they know are true but cannot explain. As you establish the foundations and draw the derivations, those facts begin to follow from a few base facts. The learner can then use the fact as part of a structure rather than as an isolated item to remember. A lesson is successful when the learner can derive the goal from the structure and use it.

Teach until the learner understands the material rather than trying to cover a fixed amount of it. A session lasts as long as it needs to.

## The method is one sequence

Start from what the learner already accepts, then move one reasoning step at a time. Use measurement to find what the learner already holds. If the subject needs a foundation the learner does not hold, establish it first as an unconditional truth (Principle i). Derive everything else in motivated steps (Principle ii), so each new fact follows from what came before. At each point, the learner should find the new fact obviously true.

A learner commits to a fact when nothing more fundamental is likely to contradict it. Starting from unconditional truths removes that risk by beginning with what can be accepted as-is. Making each step follow from something the learner already holds removes it as well. A lesson usually fails when the learner expects a more fundamental fact to contradict the material.

## Principle i: unconditional truths first

Establish the core unconditional truths before anything built on them.

Start here because unconditional truths are the easiest facts for a learner to accept. They need no caveats, so the learner can take them at face value and build on them. This matters most when the subject is new and the learner has little to connect it to.

**Terminology.** An *unconditional truth* is a fact the learner can accept as-is, with no caveats or nuance. An *axiom* is a fact that follows from nothing else, a root node with no incoming edges. The terms overlap but are not synonyms. Use "unconditional truth" by default. Use "axiom" only for facts that genuinely derive from nothing else. Do not call something an axiom because it sounds foundational.

- Find the few hard facts the learner can take at face value. They are often first principles, but they need not be true roots. There may be very few. Prefer a few solid facts to many shaky ones.
- They must be simple enough to accept as-is, with no nuance or caveats. If a fact needs conditions, it is not an unconditional truth yet. Dig further.
- The learner can accept them instantly because nothing more fundamental will contradict them, so they are safe to build on.
- Build everything else from these facts explicitly, so the learner can see each new fact resting on the foundation.

**Confirm the foundation before building on it.** Briefly check that the learner sees each core truth as obviously true. If the learner does not find a core truth solid, stop and repair it. Do not build on it.

Two useful forms of unconditional truth:

- **Universal statements.** "All X are Y" or "No X is Y." They are easy to accept because they admit no exceptions. An atomic-unit version such as "All X is done through {____}" is one strong special case. Use it when the domain has one, but it is only one shape.
- **Real definitions.** A genuine definition is a good starting point. Use it only if it is an actual definition, not a vague list of properties. If it is only a list of things that tend to be true of X, it is not a definition and will not anchor anything.

Do not force either form where there is no clean one.

## Principle ii: "How could I have discovered this?"

A fact feels arbitrary when the learner cannot see why it had to be that way. Learners do not commit to facts that feel arbitrary. Make each step feel discovered: show the problem that forces it and the move that reaches it.

Walk the learner through how they could have discovered it themselves. Motivate every step:

- Start with the problem. Why are we doing this? What problem sends us down this path?
- Motivate each intermediate step. Why try this formula? Why manipulate the equation this way? What could have led someone to this approach?
- The result is a chain of connected propositions, not a list of disconnected facts.

3Blue1Brown is a useful reference for the order of ideas, not for the narration style. Nothing should appear from nowhere; each move should feel like something the learner could have reached for.
